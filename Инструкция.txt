1. Общий интерфейс

При запуске приложения вы увидите главное окно с тремя основными пунктами меню (слева):
	1.	Читатели
	2.	Книги
	3.	Классы и параллели

Рядом располагается центральная часть, где отображаются соответствующие страницы.

Переключение между страницами

Чтобы перейти на нужную страницу, нажмите на соответствующую кнопку в левой части окна. Активная страница выделяется цветом.

2. Работа с Читателями

Нажмите кнопку «Читатели» в левом меню, чтобы открыть страницу со списком всех зарегистрированных учеников.

2.1. Поиск и фильтрация
	1.	Поиск по ФИО
	•	В поле «Поиск по ФИО» введите фамилию, имя или отчество ученика (полностью или частично).
	•	Список автоматически отфильтруется, показывая только тех, чьи ФИО содержат набранный текст.
	2.	Фильтр по Классу
	•	Раскройте список «Класс» и выберите конкретный класс или «Все», если хотите убрать фильтр.
	3.	Фильтр по Параллели
	•	Аналогично «Классу»: выберите конкретную параллель или «Все» для отключения фильтра.
	4.	Сортировать по дате сдачи
	•	«Все»: показывает без сортировки по датам возврата книг.
	•	«Сдать раньше»: сортирует по ближайшему сроку сдачи книг (раньше – выше в списке).
	•	«Сдать позже»: сортирует по последнему сроку сдачи (позже – выше в списке).

Список будет автоматически обновляться при вводе или изменении настроек фильтра.

2.2. Добавление нового ученика
	1.	Нажмите кнопку «Добавить ученика».
	2.	В открывшемся окне заполните поля:
	•	Фамилия, Имя, Отчество (только буквы).
	•	Класс и Параллель выберите из выпадающего списка.
	•	В разделе «Книги» можно указать, какие книги выдать ученику (по одной записи на строку).
	•	Нажмите «Добавить книгу», выберите нужную из выпадающего списка (для удобства доступен поиск по вводу текста), при необходимости укажите дату сдачи.
	3.	Нажмите «Сохранить ученика». Если данные заполнены корректно, новый ученик появится в списке.

2.3. Редактирование/удаление ученика
	1.	Редактирование
	•	Дважды кликните по нужному ученику в списке (или дважды кликните на строку таблицы). Откроется диалоговое окно с информацией о выбранном ученике.
	•	Внесите изменения при необходимости (ФИО, класс, параллель, список книг).
	•	Нажмите «Сохранить ученика». Изменения сразу отобразятся в общем списке.
	2.	Удаление
	•	В том же диалоговом окне, если речь идёт о существующем ученике, есть кнопка «Удалить ученика».
	•	Нажав её, вы удалите ученика полностью.

2.4. Полное удаление списка читателей
	•	Кнопка «Очистить всех» удаляет всех учеников сразу. При нажатии появляется окно подтверждения, чтобы исключить случайное удаление.

2.5. Список и статус
	•	В нижней части страницы отображается статус: «Читателей: X/Y», где:
	•	X – число фактически загруженных записей
	•	Y – общее количество отфильтрованных записей.

При прокрутке таблицы до самого низа приложение будет подгружать следующие партии записей автоматически.

3. Работа с Книгами

Нажмите кнопку «Книги» в левом меню, чтобы перейти на страницу управления книгами.

3.1. Поиск
	•	Введите часть названия или автора в строку «Поиск». Список книг отфильтруется автоматически.

3.2. Добавление новой книги
	1.	Нажмите кнопку «Добавить книгу».
	2.	В диалоге заполните:
	•	Название книги, Автор;
	•	Количество экземпляров (если нужно).
	•	При указании количества экземпляров приложение не позволит выдать читателям больше этого количества
	3.	Нажмите «Сохранить книгу». Новая книга появится в списке.

3.3. Удаление одной или всех книг
	1.	Удаление выбранной книги
	•	Выделите строку с нужной книгой в таблице (один клик) и нажмите «Удалить книгу». При этом выбранная книга исчезнет из списка и базы данных.
	2.	Очистить все книги
	•	Нажмите «Очистить все книги» и подтвердите действие во всплывающем окне.

3.4. Статус книг
	•	В нижней части страницы также есть статус «Книг: X/Y», где:
	•	X – число реально подгруженных строк модели,
	•	Y – количество отфильтрованных записей.

4. Классы и параллели

Нажмите кнопку «Классы и параллели», чтобы открыть страницу с настройками.

4.1. Управление классами
	•	В разделе «Классы» справа отображается список всех доступных классов.
	•	Добавить новый класс:
	1.	Введите класс в поле «Новый класс».
	2.	Нажмите кнопку «Добавить».
	•	Если уверены в своём выборе нажмите «Сохранить изменения»
	•	Удалить выбранное:
	•	Выберите нужный класс (клик в списке) и нажмите «Удалить выбранное».
	•	Если уверены в своём выборе нажмите «Сохранить изменения»

4.2. Управление параллелями
	•	Аналогично классам, но в разделе «Параллели».

4.3. Сдвиг учеников на следующий класс
	•	Кнопка «Сдвинуть учеников на следующий класс».
	•	Она автоматически переводит учеников на класс выше (например, с «3» на «4»).
	•	Если ученик уже в 9 классе, система попросит уточнить, нужно ли удалить такого ученика (он окончил школу) или перевести в следующий (10) класс. Для учеников последнего (11) класса есть только возможность удалить. Появится специальное диалоговое окно с несколькими вариантами действий.

4.4. Сохранение изменений
	•	Кнопка «Сохранить изменения» фиксирует внесённые корректировки в базу данных.
