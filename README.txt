# Школьная библиотека

Это приложение для управления школьной библиотекой, разработанное с использованием PyQt6 и SQLite. Приложение позволяет вести учёт учеников, книг и выдачи книг, а также настраивать конфигурацию классов и параллелей.

## Структура проекта

library_app/               # Корень проекта
├── main.py                # Запуск приложения
├── library_app.py         # Основной класс приложения
├── utils.py               # Утилитарные функции (валидация, проверка лимитов)
├── pages/                 # Страницы интерфейса
│   ├── readers_page.py    # UI и логика вкладки "Читатели"
│   ├── books_page.py      # UI и логика вкладки "Книги"
│   └── config_page.py     # UI и логика вкладки "Классы и параллели"
├── dialogs/               # Диалоговые окна для CRUD
│   ├── student_dialog.py  # Добавление/редактирование ученика
│   ├── book_dialog.py     # Добавление книги
│   ├── ambiguous_shift_dialog.py  # Обработка неоднозначного перевода
│   └── ...                # (по необходимости другие диалоги)
├── models/                # Qt-модели для таблиц
│   └── books_table_model.py
├── data/                  # Слой доступа к данным (SQLite)
│   ├── db.py              # Инициализация и соединение с БД
│   ├── books_manager.py   # Загрузка/сохранение книг
│   ├── students_manager.py# Загрузка/сохранение учеников и их книг
│   └── config_manager.py  # Загрузка/сохранение конфигурации (классы, параллели)
├── library.db             # SQLite база данных (после инициализации)
└── LICENSE                # Лицензия Apache 2.0

Основные компоненты

Точка входа — main.py

Запускает QApplication и отображает окно LibraryApp.

Ядро приложения — library_app.py

Класс LibraryApp наследует QWidget.

Инициализация данных: load_config(), load_books(), load_students().

Построение интерфейса: меню и страницы (QStackedWidget).

Методы CRUD:

add_student(), edit_student(), clear_all_students()

add_book(), delete_book(), clear_all_books()

add_class(), delete_class(), add_parallel(), delete_parallel()

shift_students() — автоматический перевод учеников.

Слой UI — пакеты pages/ и dialogs/

pages/*.py — вкладки главного окна:

ReadersPage: фильтрация, поиск, ленивый скролл, табличное представление.

BooksPage: поиск по названию/автору, ленивый скролл, QTableView + модель.

ConfigPage: редактирование справочников классов и параллелей.

dialogs/*.py — модальные формы для ввода:

StudentDialog: динамическое добавление селекторов книг, автодополнение.

BookDialog: ввод названия, автора, количества.

AmbiguousShiftDialog: выбор действий для учеников последнего класса.

Слой данных — пакет data/

db.py: создаёт таблицы (config, books, students, student_books).

config_manager.py: хранит JSON-конфигурацию классов и параллелей.

books_manager.py: CRUD для таблицы books, поддерживает quantity.

students_manager.py: CRUD для таблицы students и связей student_books, формат дат.

Утилиты — utils.py

is_valid_name(text) — проверка корректности ФИО.

count_issued, check_issued_limits — контроль количества выданных экземпляров.

Модель для таблицы книг — models/books_table_model.py

Класс BooksTableModel наследует QAbstractTableModel.

Управляет отображением трёх столбцов: Название, Автор, Количество.

Логика взаимодействия

UI-слой вызывает методы LibraryApp, которые через менеджеры data/* изменяют базу и обновляют представления.

Обновление справочников (классы, параллели) сразу отражается в фильтрах вкладки «Читатели» благодаря вызову refresh_filters().

Все формы (dialogs/) возвращают данные словарями, которые сохраняются и снова загружаются для синхронности.

Ленивый скроллинг на страницах «Читатели» и «Книги» разгружает интерфейс при больших объёмах данных.
