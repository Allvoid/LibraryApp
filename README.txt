# Школьная библиотека

Это приложение для управления школьной библиотекой, разработанное с использованием PyQt6 и SQLite. Приложение позволяет вести учёт учеников, книг и выдачи книг, а также настраивать конфигурацию классов и параллелей.

## Структура проекта

project/
├── main.py                   # Точка входа в приложение
├── library_app.py            # Основное окно приложения
├── dialogs/                  # Диалоги (добавление/редактирование учеников, книг и т.д.)
│   ├── init.py
│   ├── student_dialog.py     # Диалог для работы с учениками
│   ├── book_dialog.py        # Диалог для работы с книгами (с полем количества)
│   └── ambiguous_shift_dialog.py  # Диалог для обработки неоднозначных случаев при сдвиге учеников
├── data/                     # Модуль доступа к данным через SQLite
│   ├── init.py
│   ├── db.py                 # Соединение и инициализация базы данных
│   ├── config_manager.py     # Загрузка и сохранение конфигурации (классы, параллели)
│   ├── books_manager.py      # Загрузка, обновление и сохранение данных о книгах
│   └── students_manager.py   # Загрузка, обновление и сохранение данных об учениках
└── utils.py                  # Общие утилиты (валидация имён, проверка выдачи книг и т.д.)

## Особенности

- **Пользовательский интерфейс (UI):**  
  Реализован с использованием PyQt6. Интерфейс поддерживает добавление, редактирование и удаление учеников и книг, а также сортировку и поиск.

- **Хранение данных:**  
  Все данные (конфигурация, книги, ученики, выдача книг) сохраняются в базе данных SQLite (файл `library.db`), что обеспечивает надежное и централизованное хранение информации.

- **Модульная архитектура:**  
  Проект разделён на отдельные модули:
  - Диалоги находятся в папке `dialogs`
  - Работа с данными – в папке `data`
  - Общие утилиты – в файле `utils.py`
  - Основное окно – в файле `library_app.py`
